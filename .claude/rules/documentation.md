# Documentation

Read `docs/AGENTS.md` before adding, moving, or deleting a Markdown file. It is the
canonical protocol; do not restate it here.

The two rules broken most often:

- **One canonical place per fact.** If a page already answers this question, update
  it. A new sibling page is almost always the wrong move.
- **Delete rather than accumulate.** When you touch a page, remove nearby text that
  is stale, contradicted, or redundant, and report what you removed.
